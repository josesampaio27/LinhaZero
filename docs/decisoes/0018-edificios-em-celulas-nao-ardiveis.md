# ADR 0018: Edifícios em células não ardíveis

- Estado: aceite
- Data: 2026-10-16

## Decisão

Aplicar a definição do enunciado à letra: um edifício só conta se a célula onde está arder.

## Porquê

É simples e explicável; no FUMOD, os centros urbanos são "não ardível" (98), por isso só contam as casas na interface urbano-florestal.

## Alternativas consideradas

Contar também edifícios em células vizinhas de células ardidas (mais realista, mas muda o contrato das métricas).
