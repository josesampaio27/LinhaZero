# ADR 0014: Vista de incerteza

- Estado: aceite
- Data: 2026-10-16

## Decisão

Com incerteza ligada, os mapas mostram a probabilidade de arder até ao fim da duração; a barra de tempo só se aplica à vista "Tempo de chegada". O painel acrescenta a área com probabilidade ≥ 50% e, para edifícios e área ardida, em quantos cenários de vento cada decisão é melhor.

## Porquê

A probabilidade é calculada só no fim, por isso animá-la no tempo seria enganador.

## Alternativas consideradas

Guardar o tempo de chegada de todas as corridas para animar a probabilidade.
