# ADR 0019: Etiquetas no mapa

- Estado: aceite
- Data: 2026-10-16

## Decisão

Só se mostram os nomes dos 20 lugares com mais edifícios, e o painel só lista os lugares que o fogo atinge (até 10).

## Porquê

A grelha real tem 88 lugares e, com todos os nomes, o mapa ficava ilegível.

## Alternativas consideradas

Agrupar etiquetas consoante o zoom.
