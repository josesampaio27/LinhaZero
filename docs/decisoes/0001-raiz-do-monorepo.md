# ADR 0001: Raiz do monorepo

- Estado: aceite
- Data: 2026-10-16

## Decisão

O monorepo vive diretamente na pasta do projeto, sem uma subpasta `linha-zero/`.

## Porquê

A pasta já existia vazia e era só para isto; menos um nível de diretórios.

## Alternativas consideradas

Criar `linha-zero/` dentro da pasta.
